## 使用方法

### 启动命令
```bash
ros2 launch interbotix_xsarm_joy xsarm_joy.launch.py robot_model:=wx200 controller:=xboxone
```

### 关键特性

1. **🔄 智能姿态切换**: LB按钮具有智能切换逻辑
   - **任何非Home姿态**（包括手动移动后）→ 按LB → **Home姿态**
   - **Home姿态** → 按LB → **Sleep姿态**  
   - **Sleep姿态** → 按LB → **Home姿态**
   - 自动检测手动移动，确保先回到Home再切换Sleep
   - 显示详细日志信息告知切换原因和目标姿态
2. **特殊的扳机处理**: LT/RT 扳机现在正确映射为腰部控制
3. **简化的Y轴控制**: 只有RB控制端效器-Y方向（LB专用于姿态切换）
4. **安全的工作空间**: 添加了工作空间边界检查，防止"No valid pose"错误
5. **完整的速度控制**: 方向键控制速度和控制精度

### 注意事项

1. **按钮编号**: 某些按钮编号是估计值（如START=9, SELECT=8），如果实际不同，请告诉我具体编号
2. **扳机灵敏度**: LT/RT 扳机需要按下超过50%才会触发腰部旋转
3. **摇杆死区**: 摇杆阈值设置为0.75，可以在启动时调整

## 测试建议

现在您可以测试所有功能：

1. **基本移动**: 使用左摇杆控制端效器位置
2. **旋转控制**: 使用右摇杆控制端效器姿态  
3. **夹爪控制**: A/B 开关夹爪，X/Y 调节压力
4. **腰部控制**: LT/RT 控制腰部旋转
5. **🆕 智能姿态切换**: **LB按钮**智能管理姿态切换
   - **场景1**: 机器人在任意位置（非Home） → 按LB → 移动到**Home姿态**
   - **场景2**: 机器人在Home姿态 → 按LB → 移动到**Sleep姿态**
   - **场景3**: 机器人在Sleep姿态 → 按LB → 移动到**Home姿态**
   - **场景4**: 手动移动机器人后 → 按LB → 先回到**Home姿态**
   - 系统会显示切换原因的日志信息
6. **传统姿态控制**: START/SELECT 仍可直接切换预设姿态
